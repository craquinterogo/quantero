    1. Point and Figure: quantitative construction

    A Point and Figure (P&F) chart is a stateful, lossy transformation of an ordered price series. Think of it as a filter that remembers the current direction and records only sufficiently large price movements. X columns record upward movement, while O columns record downward movement. A new column begins only after a prescribed reversal. The horizontal coordinate therefore counts columns, not equal units of calendar time.

    Weber and Zieg's The Complete Guide to Point-and-Figure Charting: The New Science of an Old Art 1 and Prashant Shah's Trading the Markets the Point & Figure Way 2 provide practitioner context. The construction below is an original mathematical specification with explicit conventions, not a reproduction of either book. StockCharts documents the common three-box reversal and high-low methods 3.

    Scope and prerequisites

    We build a close-only chart on a fixed grid with reversal \(r\geq2\). To make the rules concrete, we work through an example with \(r=3\), so a reversal requires three boxes from the active extreme. One-box reversal variants can use different column conventions and are outside this specification. Basic inequalities, logarithms, and floor/ceiling functions are sufficient.

    1.1 Inputs and price grid

    Let \((t_i,P_i)_{i=0}^{n}\) be observations in their actual arrival order. Choose a price source (close, trade, or quote), a box size \(b>0\), an anchor \(A\), and an integer reversal \(r\geq2\). For this specification, set \(A=P_0\) once and keep it fixed:

    \[ g(k)=A+kb,\qquad k\in\mathbb Z. \]

    A box is a grid level, not an interval of elapsed time. To find the last fully reached level in each direction, use

    \[ U(P)=\left\lfloor\frac{P-A}{b}\right\rfloor,\qquad D(P)=\left\lceil\frac{P-A}{b}\right\rceil. \]

    For an upward move, use \(U\) to identify the highest grid level reached. For a downward move, use \(D\) to identify the lowest level reached. The distinction matters. Suppose \(A=100,b=1\) and the active X column ends at 104. A fall to \(100.2\) passes through 103, 102, and 101, but never reaches 100. We must therefore stop the O column at 101. Rounding to the nearest box, or using floor in both directions, would incorrectly draw an unobserved level in this example.

    1.2 Initialization

    Initially there is no column and \(P_0=A\) is an unplotted reference:

    • If the first qualifying move satisfies \(P_i\geq A+b\), create X at levels \(1,\ldots,U(P_i)\).
    • If instead it satisfies \(P_i\leq A-b\), create O at levels \(-1,-2,\ldots,D(P_i)\).
    • Otherwise do nothing.

    The first qualifying observation determines the direction. The initial column may have fewer than \(r\) boxes. After initialization, every newly reversed column has at least \(r\) boxes.

    Record the first observation, the anchor, and the initialization rule. Starting the same history at a different date can change the early chart and subsequent column alignment.

    1.3 Column state and update equations

    Store the active direction \(d\in\{+1,-1\}\), terminal level \(k\), and the ordered levels in each column. Here \(k\) means the highest X or lowest O of the active column, not the latest observed price.

    1.3.1 Active X column

    1. Extension: if \(U(P_i)\geq k+1\), append X at \(k+1,\ldots,U(P_i)\), then set \(k=U(P_i)\).
    2. Reversal: otherwise, if \(D(P_i)\leq k-r\), open the next column and draw O at \(k-1,k-2,\ldots,D(P_i)\). Set \(d=-1\) and \(k=D(P_i)\).
    3. No event: otherwise leave the chart unchanged.

    1.3.2 Active O column

    1. Extension: if \(D(P_i)\leq k-1\), append O at \(k-1,\ldots,D(P_i)\), then set \(k=D(P_i)\).
    2. Reversal: otherwise, if \(U(P_i)\geq k+r\), open the next column and draw X at \(k+1,k+2,\ldots,U(P_i)\). Set \(d=+1\) and \(k=U(P_i)\).
    3. No event: otherwise leave the chart unchanged.

    For an X top \(H=g(k)\), the reversal condition is \(P_i\leq H-rb\). For an O bottom \(L=g(k)\), it is \(P_i\geq L+rb\). Equality triggers the event. An extension and a reversal cannot both occur for one scalar price.

    The reversal column starts one box away

    A reversal at three boxes does not plot only the third box. It creates all three levels beginning one box below the old X top, or one box above the old O bottom. The old extreme is not repeated.

    1.4 Worked example: one-unit boxes, three-box reversal

    Use \(A=100,b=1,r=3\). All prices below are synthetic:

    \(i\) \(P_i\) Action Active column after observation
    0 100 Set anchor without drawing a symbol None
    1 101 Initialize X X: 101
    2 104 Extend X: 101–104
    3 102 Ignore: only two boxes below 104 X: 101–104
    4 101 Reverse at \(104-3\) O: 103, 102, 101
    5 99 Extend O: 103–99
    6 102 Reverse at \(99+3\) X: 100, 101, 102
    7 105 Extend X: 100–105
    8 103 Ignore: only two boxes below 105 X: 100–105
    9 102 Reverse at \(105-3\) O: 104, 103, 102
    10 106 Reverse and fill every reached level X: 103–106

    The final plot is:

           1  2  3  4  5
106    .  .  .  .  X
105    .  .  X  .  X
104    X  .  X  O  X
103    X  O  X  O  X
102    X  O  X  O  .
101    X  O  X  .  .
100    .  O  X  .  .
 99    .  O  .  .  .

    Dots denote empty cells. Columns 1 and 3 span different observation counts despite having the same horizontal width. At \(i=10\), the price jumps from 102 to 106 and generates four X marks in a new column. All four marks come from one observed price. They show which grid levels the update fills, not four independent transactions or four observed execution opportunities.

    1.5 Implementation recipe

    The following language-neutral pseudocode operates on grid indices rather than prices. Read append_column(direction, levels) as opening a new column and extend(levels) as adding symbols to the active column. The helper inclusive(a, z, step) includes both endpoints. For example, inclusive(3, 1, -1) produces the levels 3, 2, and 1. The labels UP, DOWN, and NONE identify the current state.

    validate b > 0, integer r >= 2, finite prices, ordered observations
A = P[0]
direction = NONE
k = 0
for p in P[1:]:
    u = floor((p - A) / b)
    v = ceil((p - A) / b)
    if direction == NONE:
        if u >= 1:
            append_column(UP, inclusive(1, u, +1))
            direction, k = UP, u
        else if v <= -1:
            append_column(DOWN, inclusive(-1, v, -1))
            direction, k = DOWN, v
    else if direction == UP:
        if u >= k + 1:
            extend(inclusive(k + 1, u, +1))
            k = u
        else if v <= k - r:
            append_column(DOWN, inclusive(k - 1, v, -1))
            direction, k = DOWN, v
    else:
        if v <= k - 1:
            extend(inclusive(k - 1, v, -1))
            k = v
        else if u >= k + r:
            append_column(UP, inclusive(k + 1, u, +1))
            direction, k = UP, u

    Reject an empty input before accessing P[0]. With a single observation, we can set the anchor but cannot determine a direction, so the result contains no columns. Use integer ticks or decimal arithmetic when possible. Floating-point error near an exact threshold can create or suppress a box, which then affects later columns. Do not introduce an arbitrary tolerance that silently changes the grid.

    For \(n\) observations and \(B\) generated symbols, explicit construction costs \(O(n+B)\) time and \(O(B)\) space. If you only need the chart structure, store each column's endpoints and event metadata instead of materializing every symbol. For example, consecutive X levels from 100 to 105 can be represented by their two endpoints. Rendering still depends on the displayed grid size.

    1.6 Other box scales

    1.6.1 Percentage / logarithmic grid

    For positive prices, define a fixed geometric grid with \(A>0\) and \(q>0\):

    \[ g(k)=A(1+q)^k,\qquad x(P)=\frac{\log(P/A)}{\log(1+q)},\qquad U(P)=\lfloor x(P)\rfloor,\quad D(P)=\lceil x(P)\rceil. \]

    The same integer-index rules apply, but each step now multiplies or divides the price by \(1+q\). From an X top \(H\), the downward reversal threshold is \(H/(1+q)^r\). From an O bottom \(L\), the upward threshold is \(L(1+q)^r\). These are not exactly \(H(1-rq)\) and \(L(1+rq)\), because percentage steps compound. For \(q=0.01,r=3,H=100\), three downward steps give approximately \(97.0590\), not 97.

    This definition is one precise percentage convention. Before comparing your chart with a platform, check whether it uses the same rounding and anchoring rules. Arithmetic boxes use a linear price axis. Geometric boxes have equal spacing on a logarithmic price axis because each step represents the same proportional change.

    1.6.2 Traditional tables and volatility-based sizes

    Traditional P&F scales use price-dependent box-size tables. Freeze the table and define the adjacent grid levels explicitly. Once the box size varies with the price range, a single constant \(b\) no longer describes all transitions. Count reversal boxes along the specified grid rather than assuming that every step has the same monetary size.

    For volatility sizing, one possible rule is \(b=\lambda\,\mathrm{ATR}_m\), with \(\lambda>0\). Define the ATR smoothing, lookback, and measurement date. A box size estimated from a training window and then frozen is reproducible. Recomputing it with future data and rebuilding earlier columns changes history. If sizes adapt online, specify how the grid is re-anchored and versioned. Treat this as a different algorithm, not as an interchangeable setting for the fixed-grid construction.

    1.7 Close-only versus high-low construction

    A close-only chart consumes one close per bar. For the common high-low, continuation-first method 3:

    • In X, first test the bar's high for extension. If it extends, ignore the low for that bar. Otherwise test the low for reversal.
    • In O, first test the low for extension. If it extends, ignore the high. Otherwise test the high for reversal.
    • If neither condition holds, ignore the bar. Initialize from a documented seed. The seed must not rely on guessing which extreme occurred first.

    A bar with high 105 and low 100, following an X top at 104 with \(b=1,r=3\), both permits extension and spans a reversal threshold. Continuation-first extends to 105 and ignores 100. Processing high and then low would instead create a reversal column. OHLC data cannot establish the intrabar order. Tick paths may contain several reversals within one bar.

    1.8 Validation and backtesting

    Check at least these cases before interpreting patterns:

    Test Required result under this specification
    Constant prices No columns
    First observation below \(A-b\) Initialize O, not X
    X top 104, next price 101.1 No reversal for \(b=1,r=3\)
    X top 104, next price 101 O at 103, 102, 101
    O bottom 99, next price 101.9 No reversal for \(b=1,r=3\)
    O bottom 99, next price 102 X at 100, 101, 102
    Repeated identical observation No new symbol
    Gap beyond several grid levels Fill all crossed levels with the observation timestamp

    Retain observation timestamps, column creation times, and extension/reversal events. A column becomes known to be complete only when the next reversal is observed. In our example, the first X column reaches 104 at \(i=2\), but its completion is not confirmed until the price reaches 101 at \(i=4\). A backtest must not label that column as complete at \(i=2\) using information that arrives two observations later.

    Choose parameters using a training sample, then evaluate the frozen choices on unseen data. Use corporate-action-consistent prices, realistic latency, fees, slippage, and executable quotes. Do not annualize returns using column count as calendar time. Ten columns might form in one session or over several weeks. Filtering small changes can make a chart easier to read, but predictive power must be tested separately. The transformation neither removes market risk nor guarantees profitable trading.
